# TicTac Pro Multiplayer (Frontend)

Neon + glassmorphism Tic-Tac-Toe platform UI with local/AI play and an online (Socket.IO) architecture scaffold.

## Dev

```bash
npm install
npm run dev
```

## Env (Online mode)

Copy `.env.example` to `.env.local` and point to your backend:

```bash
cp .env.example .env.local
```

- `VITE_API_URL` defaults to `http://localhost:5001/api`
- `VITE_SOCKET_URL` defaults to `http://localhost:5001`
